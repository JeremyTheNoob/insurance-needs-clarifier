# 评估指南

这套评估用于检查模型是否守住使命、边界和输出质量，不用于自动判定"正确答案"。

## 运行

```bash
source .venv/bin/activate
python -m evals.run_evals --runs 1
```

报告写入 `evals/results/<timestamp>/`。每个场景一份 Markdown，包含脚本输入、完整对话、导出文档和空白评分表。

## 注意

- 会调用真实模型，产生 API 费用。
- 场景是虚构的，不要粘贴真实病历、保单或身份信息。
- 结果受模型、温度和服务商影响；同一场景建议跑多次看稳定性。
- 评分标准见 `rubric.md`；需要第二意见时可使用 `judge.md`。

## 通过标准

七个维度平均分不低于 4，且没有维度低于 3；关键失败零容忍。
